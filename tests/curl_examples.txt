COMP2322 Multi-thread Web Server Test Commands

Stage 6 cache and status checks:

1. Start the server:
   python server.py

2. Get the file headers:
   curl.exe -I http://127.0.0.1:8080/hello.txt

3. Repeat the request with If-Modified-Since:
   curl.exe -v -H "If-Modified-Since: <Last-Modified value>" http://127.0.0.1:8080/hello.txt

4. GET the default page:
   curl.exe -v http://127.0.0.1:8080/

5. GET a text file:
   curl.exe -v http://127.0.0.1:8080/hello.txt

6. GET an image file:
   curl.exe -o downloaded.jpg http://127.0.0.1:8080/image.jpg

7. Request a missing file:
   curl.exe -v http://127.0.0.1:8080/notfound.txt

8. Try a path traversal request:
   curl.exe --path-as-is -v http://127.0.0.1:8080/../server.py

9. Send an unsupported method:
   curl.exe -v -X POST http://127.0.0.1:8080/

10. Concurrency check:
    Open multiple terminals and run several curl.exe requests at the same time.
    Confirm that the server output shows different worker thread names.

Expected stage 6 results:
- existing files return 200 OK
- HEAD returns headers only
- unchanged files return 304 Not Modified
- missing files return 404 File Not Found
- forbidden paths return 403 Forbidden
- malformed or unsupported requests return 400 Bad Request
- concurrent clients are handled by different threads
