COMP2322 Multi-thread Web Server Test Commands

Stage 8 logging and connection checks:

1. Start the server:
   python server.py

2. Request with Connection: close
   curl.exe -v -H "Connection: close" http://127.0.0.1:8080/hello.txt

3. Request with Connection: keep-alive
   curl.exe -v -H "Connection: keep-alive" http://127.0.0.1:8080/hello.txt

4. Get the file headers:
   curl.exe -I http://127.0.0.1:8080/hello.txt

5. Repeat the request with If-Modified-Since:
   curl.exe -v -H "If-Modified-Since: <Last-Modified value>" http://127.0.0.1:8080/hello.txt

6. Request a missing file:
   curl.exe -v http://127.0.0.1:8080/notfound.txt

7. Try a path traversal request:
   curl.exe --path-as-is -v http://127.0.0.1:8080/../server.py

8. Send an unsupported method:
   curl.exe -v -X POST http://127.0.0.1:8080/

9. Keep-alive test script:
   python .\tests\keep_alive_client.py

10. Check the log file:
    Get-Content .\logs\server.log

Expected stage 8 results:
- existing files return 200 OK
- HEAD returns headers only
- unchanged files return 304 Not Modified
- missing files return 404 File Not Found
- forbidden paths return 403 Forbidden
- malformed or unsupported requests return 400 Bad Request
- keep-alive requests reuse the same connection
- each request creates one log line in logs/server.log
