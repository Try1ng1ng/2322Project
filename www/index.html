Multi-thread Web Server

This page is served by a Python socket-based multi-thread web server. It is used for browser testing and project screenshots.

Implemented Features

  • Multi-thread request handling
  • GET for text and image files
  • HEAD request support
  • 200, 400, 403, 404, and 304 responses
  • Last-Modified and If-Modified-Since
  • Connection close and keep-alive
  • Request logging to server.log
